

1. Task / objective
To understand basic computer concepts by tracing an activity through the IPOS cycle, identifying hardware and software, and observing everyday computer systems.

| Stage | What happens in my example? | Hardware / component involved |
| :--- | :--- | :--- |

| Item / software name | Hardware or software? | Software type (if applicable) | Purpose |
| :--- | :--- | :--- | :--- |
| **CPU** | Hardware | Not applicable | The "brain" of the computer. |
| **RAM** | Hardware | Not applicable | Temporary storage for running programs and active data. |
| **Internal SSD** | Hardware | Not applicable | Permanent storage for files, applications, and the operating system. |
