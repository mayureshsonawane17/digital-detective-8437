## 4. My understanding
- **What a Git repository is:** A repository is basically a project folder tracked by Git. Instead of manually saving different copies like "project_v1", "project_final", Git takes snapshots of my files whenever I commit. This lets me look back at my history, see what changed, and work safely without worrying about losing anything.
- **Why organizing by mission helps:** Having a separate folder for each mission keeps everything neat. Instead of dumping all files, code, and notes into one giant folder, each mission has its own documentation, code, and screenshots. It makes it easy for my instructor to check my work mission by mission.
