## About This Project
In this assignment, I am exploring how my computer actually works under the hood. Over the course of 9 practical missions, I am investigating:
* How hardware and software interact through the Input-Processing-Output-Storage (IPOS) cycle.
* Navigating and managing files using the command line (Terminal).
* How the operating system manages running processes, storage, and permissions.
* The difference between compiled and interpreted languages.
* Binary, decimal, and hexadecimal number systems, along with building my own Python number converter.
* Using Git and GitHub for version control, branching, and pull requests.
* Basic networking concepts, DNS lookups, and how web requests travel across the internet.

## My Learning
Through the initial missions of this independent investigation, I have learned:
1. **Computer Fundamentals & IPOS:** How hardware components (keyboard, CPU, RAM, display, SSD) work together to take inputs, process instructions, generate outputs, and save durable data.
2. **Terminal & Operating Systems:** How to navigate directories, pipe command outputs, interpret Unix file permissions (`rwx`), and monitor active background processes by their Process IDs (PIDs).
3. **Number Systems & Python:** How to convert values manually between decimal, binary, and hexadecimal, verify them with Python, and build a working converter script while understanding character encoding standards like ASCII and UTF-8.
