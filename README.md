## Execution Rules & Structure

* **Strict Sequence:** Missions are completed in numerical order from Mission 0 to Mission 8.
* **Independent Commits:** Each mission is verified, documented in its dedicated folder README, and pushed to GitHub with a descriptive commit message before starting the next mission.
* **Privacy & Security:** Personal computer usernames, Wi-Fi details, device serial numbers, IP addresses, and private tokens are excluded or redacted.
